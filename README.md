# asteroids

learning oop and pygame from boot.dev with this little here asteroids game

## Installation

Requirements:

- Python 3.13

In your terminal:

```bash
pip install git+https://github.com/g-lok/asteroids
```

## Instructions

1. Run `asteroids` from your terminal
1. Move with `WASD`
1. Shoot with `<spacebar>`
1. Don't die
